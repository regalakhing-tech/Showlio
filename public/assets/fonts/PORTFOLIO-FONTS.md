# Portfolio fonts

Plus Jakarta Sans, Newsreader, Sora, Outfit, Urbanist and Public Sans are locally hosted Latin variable WOFF2 fonts from the official Google Fonts CSS API. Each family's SIL Open Font License is stored beside its font file as `<family>-OFL.txt`.

Source families and licenses: https://github.com/google/fonts/tree/main/ofl

Studio uses Plus Jakarta Sans. Editorial uses Newsreader and Public Sans. Spotlight uses Sora and Public Sans. Bento uses Outfit and Public Sans. Gallery uses Urbanist and Public Sans. Inter remains the workspace and system fallback. No remote font request is required when visiting a portfolio or opening its downloaded HTML.
